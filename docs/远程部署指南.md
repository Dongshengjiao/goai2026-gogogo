# 远程部署指南 · 魔力方舟 GPU 服务器

## 概览

在 Windows 本地编辑代码，在魔力方舟租用的 RTX 4090 24GB Linux 服务器上部署和评测。

```
Windows 本地                    魔力方舟 GPU 服务器
┌──────────────┐               ┌──────────────────────────────┐
│ 编辑代码      │──scp/rsync──→ │ RoboDojo + Isaac Sim 5.1    │
│ git 操作      │              │ Policy Server (WebSocket)    │
│ 提交表单      │              │ 冒烟测试 / 正式评测            │
└──────────────┘               └───────────────┬──────────────┘
                                               │ 公网 IP
                                               │
                                    ┌──────────┴───────────┐
                                    │  官方 X-Eval 评测平台   │
                                    │  RoboDojo 仿真评测      │
                                    └──────────────────────┘
```

## 1. 租用服务器

### 1.1 在魔力方舟租用 GPU

1. 登录魔力方舟控制台
2. 选择 **RTX 4090 24GB** 实例
3. 镜像选择：**Ubuntu 22.04 + CUDA 12.x**
4. 确保实例有 **公网 IP**
5. 记录以下信息：
   - 公网 IP（如 `123.45.67.89`）
   - SSH 端口（通常 `22`，部分平台可能映射到其他端口）
   - 登录密码或密钥

### 1.2 磁盘空间要求

| 用途 | 空间 |
|---|---|
| RoboDojo + Isaac Sim 安装 | ~80 GB |
| Assets 资产 | ~30 GB |
| HDF5 训练数据 | ~50 GB |
| 模型 checkpoint | ~10 GB |
| **合计** | **~170 GB（建议 200GB+）** |

## 2. 首次部署

### 2.1 从 Windows SSH 连入

```powershell
# PowerShell
ssh root@<服务器公网IP>
```

### 2.2 上传项目代码

**方式一：用同步脚本（推荐）**

在 Windows 本地项目目录：

```powershell
# 只上传项目代码（不含 RoboDojo，服务器端安装）
.\scripts\sync_to_server.ps1 -ServerIP <公网IP> -CodeOnly

# 或：上传代码 + 自动执行完整部署
.\scripts\sync_to_server.ps1 -ServerIP <公网IP> -Deploy
```

**方式二：手动 SCP**

```powershell
# 在 Windows PowerShell
scp -r ./* root@<公网IP>:/root/goai2026-robodojo/
```

**方式三：在服务器上 git clone**

```bash
# SSH 到服务器
ssh root@<公网IP>

# 克隆仓库
git clone <your-repo-url> /root/goai2026-robodojo
cd /root/goai2026-robodojo
```

### 2.3 执行部署脚本

SSH 到服务器后：

```bash
cd /root/goai2026-robodojo

# 一键部署（Vulkan + Git LFS + RoboDojo + Assets + Policy Adapter）
bash scripts/deploy_molifangzhou.sh
```

部署脚本自动完成：
1. 环境检查（GPU/CUDA/conda）
2. 安装 Vulkan（Isaac Sim 渲染依赖）
3. 安装 Git LFS
4. 克隆 RoboDojo（含 XPolicyLab 子模块）
5. 安装 RoboDojo（Isaac Sim 5.1 + Isaac Lab + CuRobo，**30-60 分钟**）
6. 下载 GOAI-2026 资产和数据（ModelScope 国内加速）
7. 安装 Policy Adapter

### 2.4 验证部署

```bash
# 环境自检
python scripts/self_check.py

# 获取公网 IP（提交时需要）
curl -s ifconfig.me

# 冒烟测试（24 配置 × 1 episode，验证链路可通）
bash scripts/smoke_test.sh
```

冒烟测试 `success_rate=0.0` 是正常的——demo 模式返回零动作，只验证链路。

## 3. 接入真实模型

### 3.1 上传模型权重

```powershell
# 从 Windows 上传 checkpoint
scp -r ./checkpoints/ root@<公网IP>:/root/goai2026-robodojo/policy_adapter/checkpoints/
```

### 3.2 修改 model.py

在 [policy_adapter/model.py](policy_adapter/model.py) 中实现 `_load_model()` 和 `get_action()`：

```python
# _load_model() 中：
from transformers import AutoModelForVision2Seq, AutoProcessor
self._model = AutoModelForVision2Seq.from_pretrained(
    str(self.ckpt_path), torch_dtype=torch.bfloat16
).to(self.device)
self._processor = AutoProcessor.from_pretrained(str(self.ckpt_path))

# get_action() 中：
obs = self._obs_history[-1]
images = [v["color"] for v in obs.get("vision", {}).values()]
inputs = self._processor(images=images, text=obs.get("instruction", ""))
outputs = self._model.generate(**inputs)
actions = self._decode_actions(outputs)
return actions
```

### 3.3 同步代码变更

每次在 Windows 本地修改代码后：

```powershell
# 只同步代码变更到服务器
.\scripts\sync_to_server.ps1 -ServerIP <公网IP> -CodeOnly
```

## 4. 启动 Policy Server

### 4.1 直接启动（开发调试）

```bash
# SSH 到服务器
ssh root@<公网IP>
cd /root/goai2026-robodojo
conda activate RoboDojo

# 启动 Policy Server
bash scripts/start_policy_server.sh
```

### 4.2 用 screen 后台运行（推荐）

```bash
# 创建 screen 会话
screen -S policy_server

# 在 screen 中启动
conda activate RoboDojo
bash scripts/start_policy_server.sh

# 按 Ctrl+A 然后 D 分离 screen（服务继续运行）
# 重新连接: screen -r policy_server
```

### 4.3 用 systemd 守护进程（生产环境）

```bash
# 创建 service 文件
sudo tee /etc/systemd/system/goai-policy.service << 'EOF'
[Unit]
Description=GOAI 2026 Policy Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/goai2026-robodojo
Environment="CUDA_VISIBLE_DEVICES=0"
ExecStart=/root/miniforge3/envs/RoboDojo/bin/python -c "..."
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable goai-policy
sudo systemctl start goai-policy
```

## 5. 提交评测

### 5.1 确认服务可达

```bash
# 在服务器上测试
curl -i http://localhost:9999

# 在 Windows 上测试（验证公网可达）
# PowerShell 不支持 websocket 测试，可用浏览器或 wscat
npm install -g wscat
wscat -c ws://<公网IP>:9999
```

### 5.2 在申请页面提交

打开 [https://xsparkai.com/goai-2026/apply](https://xsparkai.com/goai-2026/apply)，填写：

| 字段 | 值 |
|---|---|
| 队伍名称 | 你的队伍名 |
| 联系人 | 姓名 |
| 手机号 | 手机号 |
| 邮箱 | 邮箱 |
| 协议 | wss（如未配置 TLS 则选 ws） |
| 主机 | 服务器公网 IP |
| 端口 | 9999 |
| 策略名 | goai2026_policy |
| 动作类型 | ee（或 joint） |

### 5.3 端口放行

魔力方舟的安全组可能需要手动放行端口：

1. 在魔力方舟控制台找到安全组/防火墙设置
2. 添加入站规则：TCP 9999 端口，来源 0.0.0.0/0
3. 如使用 wss，还需要放行 443 端口（如用 nginx 反代）

## 7. 常见问题

**Q: 魔力方舟的实例关机后数据会丢吗？**
A: 取决于实例类型。按量计费实例关机后磁盘通常保留，但建议重要数据（checkpoint）及时下载到本地。包年包月实例磁盘永久保留。

**Q: Policy Server 需要一直运行吗？**
A: 是的。从提交评测申请到官方评测完成期间，服务必须在线。建议用 screen 或 systemd 守护。评测期间不要更换模型或动作类型。

**Q: 可以用 HuggingFace 代替 ModelScope 下载吗？**
A: 可以。设置 `USE_MIRROR=hf bash scripts/download_assets.sh`。但国内服务器用 ModelScope 更快。

**Q: Isaac Sim 安装失败怎么办？**
A: RoboDojo 安装脚本支持断点续传：
```bash
cd RoboDojo
bash scripts/install.sh --from isaacsim  # 从 isaacsim 步骤重试
```

**Q: 冒烟测试报 "Connection refused" 怎么办？**
A: 检查：
1. Policy Server 是否已启动（`ps aux | grep python`）
2. 端口是否被占用（`lsof -i:9999`）
3. 安全组是否放行 9999 端口
4. 服务器内部测试（`curl http://localhost:9999`）
