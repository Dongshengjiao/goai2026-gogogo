# 项目简介

## 项目名称

GOAI 2026 RoboDojo VLA 策略评测系统

## 项目简介

本项目面向 GOAI 2026 具身未来赛道赛题一（通用双臂协作操作能力测试），构建了一套基于 RoboDojo 基准和 XPolicyLab 策略框架的视觉-语言-动作（VLA）策略评测系统。

系统通过 WebSocket 协议对接官方 X-Eval 仿真评测平台，实现了从多视角视觉观测、自然语言指令理解到双臂末端位姿/关节角动作输出的完整感知-决策-执行闭环。覆盖 RoboDojo 基准的 12 项双臂操作任务（叠碗、推物、装箱、折衣服、挂杯子、倒液体等），每项任务含标准配置和随机化配置共 24 个评测配置。

项目采用模块化设计，核心策略适配器实现 XPolicyLab 标准 Model 契约接口，支持任意 VLA 模型的即插即用接入。当前以 Demo 模式（零动作）完成端到端链路验证，冒烟测试确认仿真器、渲染、WebSocket 通信、结果写入全链路可通。后续将接入预训练 VLA 模型（如 π0、OpenVLA 等）进行推理和微调，在 24 个评测配置上优化成功率。

项目提供从环境搭建、冒烟测试、远程部署到评测提交的全链路自动化工具链，支持 Windows 本地开发 + GPU 服务器远程部署的协作工作流。代码和文档均以开源协议（Apache 2.0 / CC BY 4.0）发布在 GitHub，为社区提供标准化的 VLA 模型接入方案和可复现的评测流程。

## 赛道信息

- 赛道：具身未来 Embodied Future
- 赛题：赛题一 — 通用双臂协作操作能力测试
- 评测平台：X-Eval 仿真与真机一体化评测平台

## 技术栈

- 仿真环境：RoboDojo Benchmark + Isaac Sim 5.1
- 策略框架：XPolicyLab
- 通信协议：WebSocket + MessagePack
- 模型框架：PyTorch + HuggingFace Transformers
- 开发语言：Python 3.10+
